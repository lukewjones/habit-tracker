Habit Tracker(in progress)

The Habit Tracker is a React Native application designed to help users build and maintain positive habits. 
It provides an intuitive interface for managing daily, weekly, or custom habits, offering tools to track progress over time.
While it is still a work in progress, it is an app that I have put a lot of effort into and has been a great stepping stone in the process of 
learning/getting hands on experience with React Native, Typescript, Expo, and even reaching into a little bit of backend with Supabase.


Features

* User Authentication: Secure login and signup with Supabase.
* Habit Management: Add, edit, and delete habits.
* Progress Tracking: Visualize progress and stay motivated.


Tech Stack

* Frontend: React Native with TypeScript
* Navigation: Expo Router
* Backend: Supabase for authentication and database management
* State Management: Context API
